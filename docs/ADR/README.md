# Architecture Decision Records

Each non-trivial design decision lives in its own file under this directory, named `NNNN-short-title.md`.

## Format

```
# NNNN: Short title

**Status:** Proposed | Accepted | Superseded by NNNN
**Date:** YYYY-MM-DD

## Context
What's the situation that forced this decision?

## Decision
What we decided.

## Rationale
Why this and not the alternatives.

## Consequences
What this implies for the rest of the system — code, schema, ops, future work.

## Alternatives considered
What we considered and why we didn't pick it.
```

## Existing context

The foundational design decisions are captured in `SPEC.md` §14 (Decisions Made) and §15 (Decisions Rejected). New decisions and any revisions to the foundational ones go here as numbered ADRs.
